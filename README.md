# Pokémon Viewer

## Frontend

Built with React and Vite.

## Production Build

Created using:

npm run build

The optimized production files were generated in the `dist` folder.

## Deployment

- Uploaded the contents of the `dist` folder to an Amazon S3 bucket.
- Created a CloudFront distribution using the S3 bucket as the origin.
- Configured `index.html` as the default root object.
